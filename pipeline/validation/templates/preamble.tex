% Floats must not drift out of the check they are evidence for. Every check
% ends with a \FloatBarrier, so a table can move within its subsection but
% never past it — in an appendix, a table three pages from its claim is a
% table the reader will not connect to anything.

% The claim under test, set apart from the narrative. A reader skimming the
% appendix should be able to read only these and know what was checked.

% Fixed-width table columns, set ragged right. Justified text in a narrow
% column stretches interword spacing badly, and a table cell is too short a
% measure for justification to look like anything but a defect.
\newcolumntype{P}[1]{>{\raggedright\arraybackslash}p{#1}}
